FreelanceFlow is a modern, web-based platform designed to connect client organizations with skilled freelancers. Built using vanilla JavaScript, HTML5, dynamic CSS, and local storage state persistence, FreelanceFlow provides a complete workspace for posting gigs, applying for open contracts, tracking working hours, messaging, and generating client invoices.

✨ Features
Multi-Role User Architecture:
Organizations: Post project gigs, review incoming applications, manage contract statuses, and track project logs.
Freelancers: Explore public directory listings, browse open gigs, apply directly to contracts, and log worked hours.
Isolated User Context & Data Privacy:
Strict data scoping ensures organizations only view their own posted gigs and applications submitted to their specific contracts.
Freelancers see their personal applications and logged work sessions privately.
Interactive Marketplace & Applications Tracker:
Publish new gigs with budget estimates and detailed scope specifications.
Instant status management (Pending, Accepted, Rejected) for client review.
Real-Time Workspace Chat:
Peer-to-peer messaging system for direct collaboration between freelancers and client organizations.
Built-In Work Logger:
Automated duration calculation between start and end timestamps for active contracts.
Invoice Studio:
Generate detailed, dynamic itemized invoices based on logged session hours and freelancer hourly rates.
Account Switcher:
Quick-switch capability to test multiple roles (e.g., Mailam Engineering College, Abc solutions, and Freelancers) seamlessly without losing state.
🛠️ Tech Stack
Frontend: HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid, Glassmorphism UI)
Logic & State Management: JavaScript (ES6+), Web Storage API (localStorage)
Styling: Custom Responsive Design System
